# SUAMS – Sample Project

A small, browser-based prototype for the Smart University Academic Management System assignment.

## Demonstrated modules
- Role-based navigation for Student, Teacher, Department Admin and Exam Controller demo roles.
- Course catalogue and simulated course registration.
- Examination form status, sample routine and result display.
- Student–teacher advising request.
- Academic notifications.
- Sample performance analytics.
- Observer design pattern implemented with a JavaScript event bus. Course registration and result publication emit events consumed by the notification module.
